How to install

1
Download the file for your computer above.
2
macOS: Open the .dmg file, drag SecretaryAI to your Applications folder, then double-click it.
Windows: Run the .exe installer and click Next → Install → Finish.
3
Sign in with your SecretaryAI account when the app opens. That's it!
4
Updates are automatic. The app notifies you when a new version is available and installs it in the background.
